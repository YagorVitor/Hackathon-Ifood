# Pitch da CompletAI

Apresentação em oito slides sobre a proposta comercial, o fluxo com foto real, a arquitetura e a integração com o MCP do iFood.

**[Pitch com as seis telas no final](completai-pitch-com-demo.html)**

[Pitch original de oito slides](index.html) · [Falas para arquitetura e demonstração](Falas-Demonstracao.md)

A versão completa tem 14 slides. As páginas 9 a 14 mostram entrada, revisão, sugestões, endereço, oferta e carrinho. Todas as imagens estão incorporadas no HTML. As notas dessas páginas contêm as falas sugeridas. O cronômetro planejado dessa versão soma 6min30s.

No GitHub, esse link mostra o código do HTML. Baixe o arquivo e abra no navegador para apresentar. Ele também pode ser aberto diretamente em `docs/pitch/index.html` depois de clonar o repositório.

## Controles para apresentar

| Tecla | Ação |
|---|---|
| Seta direita ou espaço | Próximo slide |
| Seta esquerda | Slide anterior |
| Home / End | Primeiro / último slide |
| Número e Enter | Ir ao slide escolhido |
| F | Tela cheia |
| N | Mostrar ou ocultar notas |
| T | Iniciar ou pausar o cronômetro |
| R | Zerar o cronômetro |
| B ou ponto | Escurecer ou restaurar a tela |

A apresentação inclui notas e um planejamento de cinco minutos. Em telas pequenas, os slides aparecem como documento para rolagem.

## Arquivo e dependências

O HTML foi copiado integralmente da versão fornecida pela equipe, sem alterações no design ou no conteúdo. A foto está incorporada ao arquivo; não depende da pasta Downloads. As fontes são carregadas pelo Google Fonts e têm alternativas locais caso não haja conexão.

O pitch é material de apresentação. Para conferir o estado implementado e os limites do produto, consulte os [entregáveis](../entregaveis/README.md) e os [guias técnicos](../README.md).
