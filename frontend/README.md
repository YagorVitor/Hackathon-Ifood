# Frontend da CompletAI

React, TypeScript, Vite e Tailwind CSS.

- [Instalação e execução](../README.md#iniciar-o-frontend)
- [Etapas, perfil e acessibilidade](../docs/frontend.md)
- [Referência da API](../docs/api.md)

As telas ficam em `src/steps`; os componentes compartilhados em `src/components`. O Vite encaminha chamadas para o backend na porta 8000.

Para conferir a interface, execute nesta pasta:

```bash
npm run test:accessibility
npm run test:profile
npm run test:lifecycle
npm run build
```
